AI MEDICAL IMAGE CLASSIFIER - VIVA NOTES

Project Type:
Educational Clinical Decision Support System (CDSS) for chest X-ray triage.

============================================================
BACKEND
============================================================

Core Backend Language:
- Python

Backend Framework and Libraries:
- Flask (web framework and routing)
- Flask-SQLAlchemy (ORM and database access)
- Flask-Bcrypt (password hashing)
- Werkzeug (request/file utilities)

Database:
- SQLite (local relational database)

Backend Modules in this Project:
- app.py (Flask app initialization and config)
- auth.py (register, login, OTP verification)
- routes.py (dashboard, upload, prediction, case management)
- models.py (Doctor and Patient tables)
- email_utils.py (email notifications)
- ai_logic.py (rule-based helper logic)

Backend Features:
- Doctor authentication and session management
- Email OTP verification flow
- Patient case storage and history
- Image upload handling and validation
- AI prediction API endpoint
- Confidence threshold logic for pneumonia output

============================================================
AI MODELS USED
============================================================

1) Pneumonia Classification Model:
- Transfer learning with MobileNetV2 (TensorFlow/Keras)
- Binary classes: NORMAL vs PNEUMONIA
- Saved file: models/model.h5

2) Chest X-ray Suitability/Detection Stage:
- CLIP model from Transformers: openai/clip-vit-base-patch32
- Library stack: Transformers + PyTorch
- Used to check whether uploaded image is a chest x-ray

3) Additional Trained Detector Artifact:
- File: models/xray_detector.h5
- Trained as chest_xray vs not_chest_xray detector (project artifact)
