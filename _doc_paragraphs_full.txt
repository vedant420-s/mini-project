0035|Normal|Abstract
0036|Normal|CuraVision AI is an educational AI-powered clinical decision support system that assists healthcare professionals in preliminary pneumonia triage using Chest X-ray (CXR) images. The updated system now combines model inference, doctor authentication, case management, and AI-generated support text in one integrated workflow.
0037|Normal|The proposed system uses a two-stage AI pipeline with clinical workflow integration:
0038|Normal|Stage 1: Chest X-ray Suitability Validation - A CLIP-based detector checks whether the uploaded image is a valid chest X-ray before diagnosis, reducing Out-of-Distribution (OOD) errors.
0039|Normal|Stage 2: Pneumonia Classification - Valid chest X-rays are classified as NORMAL or PNEUMONIA by a TensorFlow/Keras transfer-learning model (MobileNetV2-based).
0040|Normal|The models are integrated into a Flask web application with doctor login, OTP verification, case history, confidence reporting, and an AI Helper page for symptom-based recommendations.
